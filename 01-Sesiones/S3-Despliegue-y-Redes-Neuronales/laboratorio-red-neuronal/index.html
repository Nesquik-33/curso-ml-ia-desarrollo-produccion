Palabras de hoy

PalabraQué es
NeuronaSuma ponderada de entradas + una función. Los pesos se aprenden.
CNNRed convolucional: capas de filtros que recorren la imagen.
RasgosLos números que la red saca de una foto: aquí, 576.

A · La idea

De una neurona a una red convolucional

Neurona

Multiplica cada entrada por un peso, suma y aplica una función. La regresión logística de S1 es, de hecho, una sola neurona.

Red

Muchas neuronas en capas. Entrenar = ajustar los pesos para equivocarse menos, con muchos ejemplos.

Convolucional

Para imágenes: pequeños filtros recorren la foto. Las primeras capas ven bordes; las últimas, partes como orejas u ojos.

A · El truco de hoy

Transferencia: red congelada + cabeza nueva

Por qué así

  • Entrenar una CNN desde cero en CPU: 566 s y 86,4 % (con CIFAR-10, estudio previo).
  • Con MobileNet congelada + cabeza a 128×128: 93,1 % en test (720 fotos) y la cabeza se entrena en segundos (estudio previo).
  • Los pesos de MobileNetV3-small ocupan 10,3 MB y se descargan una vez.

Ojo: no es magia

  • ImageNet, con el que se entrenó MobileNet, ya contiene perros y gatos: la red ya «sabe» bastante de ellos.
  • Por eso funciona tan bien con tan pocos datos: es transferencia, no una red que aprenda de cero.

B · Los datos

Oxford-IIIT Pet: fotos reales de gatos y perros

El conjunto

  • Archivo images.tar.gz: 791,9 MB; dentro, 2 400 fotos de gato y 4 990 de perro (contadas por el script).
  • La etiqueta va en el nombre del fichero: inicial mayúscula = gato (Abyssinian_142.jpg), minúscula = perro (yorkshire_terrier_166.jpg).
  • Usamos 300 por clase (equilibrado), elegidas con semilla 42; reparto 70/15/15 train/val/test.
  • Cada foto: recorte centrado a cuadrado y reducción a 128×128 (el mismo paso al predecir).

D · Leer el resultado

93 % = 7 de cada 100 fotos fallan

Las cifras

  • Estudio previo: 93,1 % en 720 fotos de test (IC95 91,1–94,9 %).
  • Hoy: 93,3 % en 90 fotos de test (84 bien, 6 mal). Con tan pocas fotos, unos puntos arriba o abajo son azar.
  • En validación salió 87,8 % (90 fotos): por eso no se elige con test.

En producción

  • De cada 100 fotos, unas 7 se equivocan: hay que decidir qué pasa con ellas.
  • Fotos raras (dos animales, un dibujo, otra especie) no son «ni perro ni gato»: el modelo siempre elige uno.
  • Una probabilidad cerca de 0,5 es una buena señal de duda.

D · Hacia producción

Siguiente paso: una API que reciba la imagen

API con imagen

Como la de S2, pero recibiendo un fichero de imagen. En el estudio previo, decodificar, recortar y predecir una foto de 150 KB: 3,9–4,6 ms; a través de FastAPI con su cliente de pruebas, mediana 52 ms.

ONNX para una imagen ligera

Con PyTorch, los paquetes ocupan unos 982 MB; exportando a ONNX y sirviendo con ONNX Runtime, unos 264 MB (modelo de 3,7 MB).

Hoy no

Sin Docker ni API en este laboratorio: el modelo ya está registrado con su firma, que es lo que necesitaría ese servicio.
